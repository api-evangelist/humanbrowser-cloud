# humanbrowser-cloud — removed from the catalog

This provider was removed from the API Evangelist network and the APIs.io catalog on 2026-11-11.

This was a catalog policy decision, not a request from the company: APIs.io does not list CAPTCHA-solving services, whose purpose is defeating other parties' bot protection. Everything previously published here (API definitions, artifacts, profile, rating) has been removed, and the company is on the delisting registry so pipelines will not re-add it.

# Human Browser

> Cloud Chromium for AI agents. Drive a real residential-IP browser via A2A 1.0, MCP, or REST. Live viewer + human-in-the-loop takeover.

humanbrowser.cloud is a hosted browser-automation platform purpose-built for AI agents. Agents send natural-language goals; the platform runs a real Chromium session on a clean residential connection, observes via a live viewer URL the user can watch and take over at any moment.

## Endpoints

- **A2A 1.0:** https://agent.humanbrowser.cloud/a2a (JSON-RPC + SSE, Bearer-token auth)
- **MCP:** https://agent.humanbrowser.cloud/mcp (Streamable HTTP transport) OR via npm `npx -y @virixlabs/humanbrowser mcp`
- **REST account API:** https://humanbrowser.cloud/api/{trial-balance,account,topup,buy,spawn}
- **Agent Card:** https://agent.humanbrowser.cloud/.well-known/agent-card.json

## Compliance

Human Browser is positioned for legitimate, user-authorized web tasks: research, monitoring, form-fill on services the user owns credentials for, gathering public data, comparison shopping. It is not marketed or operated as a tool for circumventing access controls, evading bot detection, or scraping behind authentication walls without the data subject's permission.
